01 Software Engineer · Dapper Labs · 2025 — Present

Atlas — a multi-brand frontend platform for three consumer apps

Atlas is the consolidated Next.js codebase that ships as NBA Top Shot, NFL All Day, and Disney Pinnacle. Environment variables at build time swap branding — theme, tokens, assets, copy — so one repo serves three differently-branded production apps. I own the shared user-profile surface and the design system underneath it.

Problem
Three consumer products share enough DNA — account, marketplace, transactions — that maintaining separate frontends multiplied effort and drift. We needed one platform that could ship three brands without losing per-product polish.
My work
Led end-to-end build of the shared user profile / account surface used by all three apps. Architected the design system: 25+ accessible primitives on Tailwind, shadcn, and Radix, with theming wired to the env-driven token layer. Set up a Figma-MCP pipeline so designs flow into code without manual translation.
Outcome
Design system adopted across 10+ feature areas, shipped into all three production apps. New-feature build time down ~40%. Task completion on the profile surface improved 35%.
